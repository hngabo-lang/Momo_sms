# MoMo SMS 

## Team: Data Wranglers
## Team Members
- Aristote Henry Ngabo
- Precious Azubuike
- Griphen Mweene

## Overview
Parses MTN Mobile Money SMS transaction data (exported as XML), cleans and
categorizes it, loads it into SQLite, and serves it to a static dashboard.
